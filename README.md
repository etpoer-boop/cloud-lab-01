# cloud-lab-01
CodeLab — облачная платформа сервисов

О проекте

CodeLab — небольшой веб-проект, созданный для знакомства с разработкой приложений в удалённой среде. Он позволяет получать информацию о сервере и управлять списком доступных облачных ресурсов с помощью HTTP-запросов.

Проект разработан на JavaScript с использованием Node.js и Express.

Возможности

* Просмотр главной страницы приложения.
* Получение информации о запущенном сервере.
* Вывод списка доступных ресурсов.
* Поиск отдельного ресурса по его идентификатору.
* Добавление новых ресурсов через POST-запрос.
* Получение персонального приветствия по имени пользователя.
* Обработка некорректных запросов и отсутствующих записей.

Запуск приложения

Для начала работы необходимо установить зависимости:

npm install

Затем запустить сервер:

npm start

После запуска приложение будет доступно через порт 3000.

Доступные адреса

HTTP-метод Адрес Результат
GET / Стартовая страница
GET /api/status Информация о сервере
GET /api/hello Приветствие гостя
GET /api/hello?name=Anna Приветствие по имени
GET /api/services Все доступные ресурсы
GET /api/services/:id Ресурс с указанным ID
POST /api/services Создание нового ресурса

Обработка запросов

При работе API предусмотрены следующие ответы:

* 200 OK — запрос успешно обработан.
* 201 Created — новый ресурс создан.
* 400 Bad Request — переданы некорректные данные.
* 404 Not Found — запрашиваемый адрес или ресурс не найден.

Для добавления ресурса необходимо передать JSON с полями name и category.

Пример:

{
  "name": "Облачная база данных",
  "category": "database"
}

Настройки окружения

Конфигурация проекта размещена в .devcontainer/devcontainer.json. Она определяет используемый образ Node.js, устанавливаемые зависимости и перенаправление порта приложения.

Имя приложения можно изменить с помощью переменной окружения APP_NAME.

Хранение данных

На текущем этапе список ресурсов находится в массиве JavaScript. Поэтому новые записи доступны только во время работы сервера. После его перезапуска исходный список восстанавливается.
