# cloud-lab-01
Cloud Lab — Моё приложение в GitHub Codespaces

1. Название проекта

Cloud Lab — облачное веб-приложение.

2. Назначение проекта

Проект создан в рамках практической работы для изучения облачной среды разработки GitHub Codespaces, базовых команд Linux, работы с Node.js и создания HTTP API.

Приложение позволяет просматривать состояние сервера, получать список облачных сервисов, находить отдельные сервисы по идентификатору и добавлять новые сервисы.

3. Использованные технологии

* GitHub Codespaces — облачная среда разработки.
* Linux — операционная система окружения.
* Node.js — серверная платформа.
* Express.js — создание веб-сервера и HTTP-маршрутов.
* JavaScript — язык программирования.
* Git и GitHub — контроль версий и хранение проекта.
* npm — управление пакетами.

4. Установка и запуск проекта

Для установки зависимостей выполните команду:

npm install

Для запуска приложения:

npm start

После запуска сервер будет доступен на порту 3000.

5. HTTP-маршруты приложения

Метод Маршрут Назначение
GET / Главная страница приложения
GET /api/status Получение состояния сервера
GET /api/services Получение списка всех сервисов
GET /api/services/:id Получение сервиса по идентификатору
POST /api/services Добавление нового сервиса
GET /api/hello Получение приветствия
GET /api/hello?name=Anna Приветствие пользователя по имени

6. Особенности приложения

* Данные о сервисах хранятся в массиве в оперативной памяти.
* Для добавления сервиса используются JSON-запросы.
* При отсутствии обязательных полей возвращается ошибка 400.
* При поиске несуществующего сервиса возвращается ошибка 404.
* При успешном добавлении сервиса возвращается статус 201.
* Название приложения можно задавать через переменную окружения APP_NAME.

7. Конфигурация облачного окружения

Для настройки GitHub Codespaces используется файл .devcontainer/devcontainer.json.

В нём указаны образ Node.js, перенаправление порта 3000, установка зависимостей и переменная окружения APP_NAME.
